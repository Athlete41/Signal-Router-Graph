## 任务描述

1. 重构示波器节点 — 输入从 `(float,)` 改为 `QByteArray` 二进制协议包，工作线程负责解析协议 → 放大倍数/偏移处理 → 环形缓冲区
2. 新建信号发生器节点 — 定时生成正弦波数据，按协议编码为 QByteArray 输出

## 协议设计

```
[帧头2B: 0xAA55][采样间隔4B: uint32(μs)][数据数2B: uint16][数据N*4B: float32 LE][校验1B: XOR]
```

1. **示波器输入改为 QByteArray** — registerSlot 和 registerSignal 的 argsType 改为 (QByteArray,)
2. **协议解析在工作线程完成** — OscilloscopeSampler.writeData 内完成 parse → 处理 → 写入 ring buffer

5. **保持帧握手** — frameReady → renderComplete 循环不变，ring buffer 继续保留
