## 任务描述

实现一个"示波器"（Oscilloscope）可视化节点，接收外部数据源的浮点数信号，在工作线程中使用环形缓冲区处理数据，通过帧握手协议确保主线程渲染完成后才发送下一帧数据。

## 约束条件

1. **多线程** — 数据处理必须在工作线程（QThread）中完成，不得阻塞主线程 UI
2. **帧握手** — 工作线程发帧后必须等主线程 `renderComplete` 信号才能发下一帧，但缓冲区的写入不受帧发送阻塞
3. **环形缓冲区** — 带覆盖检测（overwrite_count + overwrite_positions），覆盖 position 为 buffer 内的索引
4. **红色 X 标记** — 在波形图上标记覆盖发生的位置（交叉红线）
5. **信号桥接模式** — 跨线程用 `pyqtSignal → slot`（AutoConnection 自动排队），不用 `QMetaObject.invokeMethod` 做控制命令
6. **tppath** — `("可视化", "示波器")`，不可重名
7. **端口顺序** — 输入端口 `argsType=(float,)`，只有一个输入，不存在顺序问题
