# 渲染管线控制 — 心跳检测方案

## 痛点

QGraphicsProxyWidget 切断了 widget parent 链，导致 `isVisible()`、`visibleRegion()`、`window()` 均不可靠。而 paintEvent 走的是场景渲染管线，proxy 不影响它。因此 paintEvent 是否被调用是判断"实际可视"的最可靠信号。

## 方案

创建 HeartbeatWidget，重写 paintEvent 只做计数。定时器永不停止，每次 tick 比较计数判断心跳。

```python
class HeartbeatWidget(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.beat_count = 0

    def paintEvent(self, event):
        self.beat_count += 1
```

```
tick → beat_count 变了？ → 复位停止标志，正常渲染
     → beat_count 没变超过 T？ → 设停止标志，跳过业务逻辑
```

T 缺省 1.5s。恢复由 Qt 初始 paint 自动触发，定时器一直跑，无需额外唤醒。

## 实现步骤

1. 新建 `heartbeat.py` — HeartbeatWidget
2. 挂载到待监测控件的父级
3. 定时器逻辑加心跳检测，移除旧的可见性判断代码
